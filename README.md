# MIPAAS
Medical Image Processing as a Software Service.

See [docs/PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md) for the repository layout, API conventions and data paths.

```bash
# backend (from apps/backend)
pip install -r requirements.txt && python wsgi.py     # http://localhost:8080
# frontend (from apps/frontend)
npm install && npm run dev                            # http://localhost:3000
```
